# hw/ — KiCad 9 project (generated schematic)

| Path | What |
|---|---|
| `design.py` | **Source of truth for the schematic connectivity.** Parts, nets, notes per sheet. FPGA nets are read from `../pinmap.csv`. |
| `tools/build.py` | Regenerates the library and all sheets, runs `kicad-cli sch erc`, exports the netlist and checks every net in `design.py` against it. |
| `tools/gen_lib.py` | Builds `lib/waffle.kicad_sym` (custom parts from datasheet pin tables + a power symbol per rail). |
| `tools/gen_sch.py` | Schematic writer: places symbols on a grid, one wire stub + global label (or power symbol) per pin, no-connect flags elsewhere. |
| `tools/symlib.py`, `tools/sexp.py` | KiCad S-expression / symbol-library helpers. |
| `waffle.kicad_pro`, `waffle.kicad_sch`, `sheets/*.kicad_sch` | The project. Root sheet + 9 hierarchical sheets. **Generated — do not hand-edit**; change `design.py` and rebuild. |
| `lib/waffle.kicad_sym`, `lib/waffle.pretty/` | Custom symbols/footprints (`lib/ddr3_x16_balls.json` is the DDR3L ball map extracted from the Alliance datasheet). |
| `waffle.kicad_pcb`, `waffle.kicad_dru` | Board (generated by `tools/gen_pcb.py` from the exported netlist: footprints + nets, stack-up, outline, floorplan, rule area, GND zones) and custom DRC rules. |
| `tools/gen_pcb.py`, `tools/impedance.py` | Board generator (also writes net classes/rules into the project; power islands on L4) and the PCBWay 8-layer impedance geometry it imports. |
| `tools/place_opt.py` | Scores the four rotations of each anchored part by signal ratsnest length (used to orient the DDR3, PHY, hub, FT2232H, ESP32, Si5351, CH224K). |
| `tools/import_ses.py`, `tools/route_report.py` | Import a Freerouting `.ses` into the board; write `route-report.md` (DDR3 lane lengths vs DQS/CK, pair skews, nets without copper). |
| `tools/bga_escape.py`, `tools/export_dsn.py`, `tools/finish_route.py` | Deterministic BGA fan-out pre-route; DSN export with router-friendly rules (`POWER_REROUTE=1` exports a power-nets-only job); post-route pipeline (import, fill, plane vias, power widening, DRC clean-up, impedance widening, DRC, report, renders). |
| `layout-practices.md` | The standard-practice checklist for this board with before/after status (D59). |
| `tools/ddr_bus.py` | DDR3 bus router (D59, the reference pattern): dog-bone vias, lattice paths under the BGAs to planned exit rows (z3 plan: one net per side/row/layer, order kept per layer, pairs adjacent), straight corridor lines at 0.15 mm. Run after `bga_escape.py` with `SKIP_NETS=DDR3_` and `fix_open_pads.py`. |
| `tools/ddr_plan.py` | DDR3 bus plan (D59): z3 assignment of one layer per net (row slots at both chips, no same-layer crossings, pairs together, few band vias) written to build/ddr_layers.json. |
| `tools/fix_open_pads.py` | Connects plane-net pads (GND, 1V35, 1V1, 3V3, 5V) that have no path to their plane: a stub to a connected neighbour or a new via that lands in connected fill, at the board rules; own connectivity, re-runnable after hand edits; reports the pads it cannot reach (D58). |
| `tools/fix_pwr_fill.py` | Repairs the power distribution of an already-routed (or hand-edited) board without touching tracks: narrow 1V1/1V35 feed strips, the 1V35 island under the DRAM's capacitors, all fills at 0.1/0.15 mm so they pass between via rows, a second 3V3 pour on B.Cu; reports how many pieces each rail's copper is in (D58). |
| `tools/staged_route.sh`, `tools/ddr3_tune.py`, `tools/stitch_vias.py`, `tools/rip_nets.py` | Staged routing driver (stage 1 = DDR3 + pairs at wider spacing, stage 2 = the rest), DDR3 length matching by meanders (reports what must be rerouted by hand), GND stitching vias, rip named nets back to their escapes. |
| `tools/ddr_swap.py`, `tools/ddr_corridor.py` | Experiments kept for a later pass (D57): crossing-free DDR3 pin assignment written into `pinmap/assignment.toml`, straight-line corridor router for the DRAM–FPGA bus. Not used on the current board. |
| `tools/plane_vias.py`, `tools/power_widen.py`, `tools/drc_cleanup.py`, `tools/merge_ses_nets.py` | Vias for plane-net pads; wide switch nodes / rails and multi-via inductor outputs; removal of router copper that violates clearance; merge of selected nets from a session file. |
| `route-report.md`, `waffle-board-top.png`, `waffle-board-bottom.png` | Current routing state: DDR3 lane lengths, pair skews, remaining unconnected pads; renders. |
| `tools/check_stm32_af.py` | Verifies every STM32 peripheral signal in `design.py` against ST's open pin data XML (`build/stm/STM32H743ZITx.xml`). |
| `waffle-schematic.pdf` | Last exported PDF of all sheets. |
| `connection-report.md` | **Review this instead of the PDF**: per-chip pin → net tables generated from `design.py`. |

```sh
python3 hw/tools/build.py          # regenerate + ERC + netlist verification (needs kicad-cli 9)
kicad-cli sch export pdf --output hw/waffle-schematic.pdf hw/waffle.kicad_sch
python3 hw/tools/gen_pcb.py         # board from build/sch/waffle.net (OVERWRITES hw/waffle.kicad_pcb)
kicad-cli pcb drc --severity-all --format report --output build/drc.rpt hw/waffle.kicad_pcb
# routing (Freerouting 1.9.0 under Xvfb; 2.1.0 ignores -mp and writes no session when killed — see D51)
python3 hw/tools/gen_pcb.py && python3 hw/tools/bga_escape.py U1 U2 && python3 hw/tools/export_dsn.py build/waffle.dsn
xvfb-run -a java -jar freerouting-1.9.0.jar -de build/waffle.dsn -do build/waffle.ses -mp 6 -oit 1   # ~2 h
python3 hw/tools/finish_route.py build/waffle.ses      # import, fill zones, widen, DRC, route-report.md, renders
```

The schematic is drawn in "netlist style": every pin is labelled rather than wired point-to-point. That keeps it fully regenerable from `design.py` and lets `kicad-cli` prove connectivity; readability comes from the per-sheet notes and the consistent net names (`pinmap.csv` names in upper case, `DDR3_*`, `FMC_*`, `ULPI_*`, `HDMI_*`, …). Hand-tidying a sheet in KiCad is fine once the connectivity is frozen, but any later change should go back through `design.py`.

Sheets: power, fpga_io, fpga_pwr, config, ddr3, stm32, usb, clocks_audio, expansion.
